# ระบบจัดทำข้อเสนอโครงการจัดจ้างภาครัฐ (Prime Proposal Report)
### บริษัท ไพร์มดิจิทัลคอนซัลแทนท์ จำกัด (Prime Digital Consultant Co., Ltd.)

เว็บแอปพลิเคชันสำหรับจัดทำเอกสารข้อเสนอด้านเทคนิคโครงการภาครัฐตามระเบียบงานจัดซื้อจัดจ้าง พร้อมระบบ Export เป็นไฟล์ Microsoft Word (.docx) ตามมาตรฐานหนังสือราชการไทย (ฟอนต์ TH Sarabun New 16pt, จัดตาราง, หัว/ท้ายกระดาษ, เลขหน้า และสารบัญอัตโนมัติ)

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. การจัดการหน้าปก ปกหลัง และสารบัญอัตโนมัติ
- **หน้าปก (Front Cover)**: รองรับการอัปโหลดภาพปก หรือใช้หน้าปกทางการมาตรฐาน พร้อมระบุรหัสเอกสาร ชื่อโครงการ หน่วยงานผู้ว่าจ้าง บริษัทผู้ยื่น และวงเงินงบประมาณ
- **สารบัญ (Table of Contents)**: สร้างสารบัญหัวข้อและเลขหน้าอัตโนมัติ (Header / Footer "หน้า X จาก Y")
- **ปกหลัง (Back Cover)**: รองรับการแทรกภาพปกหลัง หรือสร้างปกหลังปิดเล่มพร้อมตราสัญลักษณ์และข้อมูลติดต่อของ บริษัท ไพร์มดิจิทัลฯ

### 2. โครงสร้างเนื้อหา 5 ส่วนครบถ้วนตามโจทย์
- **ส่วนที่ 1: บทนำและภาพรวมโครงการ** (ความเป็นมา วัตถุประสงค์ ประโยชน์ ขอบเขตงาน กรอบระยะเวลา งบประมาณ)
- **ส่วนที่ 2: แผนการดำเนินงาน (Gantt Chart & งวดงาน)**
  - แผนภูมิแกนต์ (Gantt Chart) ปรับแก้ไขและแสดงผลตลอดระยะเวลาโครงการ
  - เรนเดอร์เป็นภาพ PNG ความละเอียดสูงฝังลงในเอกสาร Word อัตโนมัติ
  - ตารางแจกแจงงวดงานและผลส่งมอบ (Milestones & Deliverables) พร้อมคำนวณร้อยละและวงเงิน
- **ส่วนที่ 3: กรอบแนวคิดและวิธีการดำเนินงาน (TOR Mapping)**
  - แทรกภาพไดอะแกรมกรอบแนวคิด (Conceptual Framework Diagram) หรือสร้างไดอะแกรมสถาปัตยกรรม 4 ชั้นมาตรฐาน
  - **ระบบบันทึก TOR ทีละข้อ**: ระบุข้อกำหนด TOR ของหน่วยงานรัฐ ควบคู่กับแนวคิดและวิธีการดำเนินงานที่บริษัทเสนอ เครื่องมือ/เทคโนโลยี และผลส่งมอบ
- **ส่วนที่ 4: คณะผู้ดำเนินงาน & แผนบริหารความเสี่ยง**
  - รายชื่อบุคลากร คุณวุฒิ ประสบการณ์ และใบรับรอง (ดึงจากคลังทีมงาน Master Pool หรือเพิ่มใหม่)
  - แผนบริหารความเสี่ยง (Risk Matrix) ด้านเทคนิค บุคลากร เวลา ขอบเขต ความปลอดภัย พร้อมมาตรการลดความเสี่ยง
- **ส่วนที่ 5: ประวัติและประสบการณ์ของบริษัท (พร้อมระบบกรองปีผลงาน)**
  - ข้อมูลนิติบุคคล ทุนจดทะเบียน วิสัยทัศน์ และใบรับรองมาตรฐาน (ISO 29110, ISO 27001, ที่ปรึกษากระทรวงการคลัง)
  - **ระบบจำกัดอายุผลงาน (Year Limitation Filter)**: เลือกระยะเวลาย้อนหลังไม่เกิน 3 ปี, 5 ปี หรือกำหนดเอง พร้อมแจ้งเตือนหากผลงานเกินเกณฑ์ และคำนวณมูลค่ารวมอัตโนมัติ

### 3. ระบบ AI ตรวจความสอดคล้องและคำผิด (Consistency & Spelling Auditor)
- ตรวจสอบความสอดคล้องของระยะเวลา (Gantt Chart vs บทนำ)
- ตรวจสอบยอดเงินและร้อยละงวดงานให้ครบ 100%
- ตรวจสอบความครบถ้วนของ TOR ทุกข้อ
- ตรวจสอบเกณฑ์ปีของผลงานบริษัท
- สแกนคำผิดภาษาไทยและแบบแผนคำศัพท์ราชการ (เช่น ลายเซ็นต์, เวปไซต์, เซ็นต์สัญญา ฯลฯ)
- รองรับการเชื่อมต่อ Google Gemini API Key สำหรับการวิเคราะห์ภาษาและความสอดคล้องเชิงลึก

### 4. การจัดการข้อมูลและการ Export
- **บันทึกอัตโนมัติ (Auto-save)**: ข้อมูลถูกจัดเก็บใน LocalStorage ของเบราว์เซอร์ ไม่ต้องกลัวข้อมูลสูญหาย
- **สำรองและนำเข้าข้อมูล (JSON Backup & Restore)**: ส่งออกเป็นไฟล์ `.json` เก็บเป็นเทมเพลตโครงการได้
- **ดาวน์โหลด Word (.docx)**: กดปุ่มเดียว Generate ไฟล์ Word คุณภาพสูง ฝังตาราง รูปภาพ และฟอนต์มาตรฐานพร้อมนำไปปรับใช้หรือพิมพ์ได้ทันที
